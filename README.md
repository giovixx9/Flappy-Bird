# 🐦 Flappy Bird Android

Un bellissimo gioco Flappy Bird per Android con UI moderna, animazioni fluide e GitHub Actions per build automatica.

## 🎮 Gameplay
- Tocca lo schermo per far volare l'uccello
- Evita i tubi
- Accumula punti
- Condividi il tuo high score!

## 🛠️ Tech Stack
- **Linguaggio**: Kotlin
- **UI Framework**: Jetpack Compose
- **Android API**: 28+
- **Build System**: Gradle

## 📦 Build & Deploy
Questo progetto usa **GitHub Actions** per:
- ✅ Build automatica su ogni push
- ✅ Test unitari
- ✅ Generazione APK
- ✅ Release automatiche

## 🚀 Come iniziare
```bash
git clone https://github.com/giovixx9/Flappy-Bird.git
cd Flappy-Bird
./gradlew build
./gradlew installDebug
```

## 📱 Requisiti
- Android 9.0+ (API 28)
- 50MB di spazio libero
- Schermo touch
